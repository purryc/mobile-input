# WorkBuddy 参数输入演示脚本

核对日期：2026-11-03。适用于新版平板演示 WorkBuddy 与 Mac WorkBuddy 的共享输入组件；本轮验证使用本地浏览器和原生接口模拟，没有提交真实 Mac 任务。

## 一次说完

> 我想做一个十分钟的演示文稿，介绍今年的产品。背景用灰色，字体用黑色，主题色用红色。请参考我的文件，添加一些产品照片。布局我画一下，左边是今年产品总览，右边是分产品的介绍。

预期 **7 个入口**：时长、背景色、字体色、主题色、文件、照片、布局。入口由文字识别产生；不会自行打开选择器、选择文件或发送。

## 当前五类控件

| 控件 | 可说的例子 | 操作与边界 |
| --- | --- | --- |
| 颜色 | 背景用灰色；字体是黑；主色是红；主题色改为蓝色 | 背景、字体、主题色分别调整；主色与主题色是同一用途。点击后调色，手选值保留。红／灰／黑只给色点着色，边框跟随应用主题。 |
| 时长 | 讲十分钟；做一个十分钟的演示文稿 | 1–60 分钟，数字编辑或每次增减一分钟；不识别为范围内的值不会被擅自截断。 |
| 文件 | 参考我的文件；参考产品资料；添加文档 | 选择后明确采用。平板生成链路支持 PDF／TXT／Markdown，不把 DOCX／PPTX／XLSX 当作已实现的解析格式。 |
| 照片 | 添加一些产品照片；还有一些产品的照片；参考产品图片 | 点击选择照片并采用，支持 PNG／JPEG／WebP。提到照片不会自动选择任何私人图片。 |
| 布局 | 布局我画一下；产品展示页的布局我画一下 | 打开空白画板，绘制后采用。空画板不阻止发送；已画但未采用的笔迹需采用或清空。 |

平板生成材料仍受现有约束：单件 8 MB、最多 12 件、总计 24 MB；传输和校验成功后才算采用。真实 Mac 的附件还必须得到目标应用接受的回执。

## 建议演示顺序

1. 大屏打开 WorkBuddy 新建任务首页；手机取得当前权威状态后显示 WorkBuddy 输入页。
2. 用按住或点击开关录入上面的台词，主动停止听写。确认七个入口同时出现。
3. 依次打开三个颜色入口，分别调整灰、黑、红；一次只打开一个控件。
4. 选择虚构产品资料与照片并采用。布局画左右两区，再采用草图。
5. 可点击“说清需求／整理要点／精简指令”润色。参数入口及已采用材料应保留；也可以撤销。
6. 明确点击发送。平板接受前保留首页；接受后显示用户消息、实际执行状态与底部输入框。

## 口语与断句补验

- “背景是。灰色。字体是。黑色。主题色是。红色。参考产品图片。” → 三个独立颜色和照片。
- “背景用灰色，字体用黑色，主色用红色，主题色改为蓝色。” → 背景、字体不变，主题色只留蓝色入口。
- “不用产品照片”“背景不是灰色” → 不生成对应的正向建议。
- “背景是。明天下午开会。红色。” → 不跨无关句子把红色配到背景。

这是有边界的本地规则识别，不保证任意自然语言都能转为控件。旧演示中的截图、录屏、路径、范围、格式、模板、尺寸、数量属于原有其他流程，本轮未扩展成新版真实 WorkBuddy 参数能力。
