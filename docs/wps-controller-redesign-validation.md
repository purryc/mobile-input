## 行为

- 激光按钮开关真实姿态采集，每次开启重新校准；翻页、切换、后台和断线释放。画笔保持按下才绘制，笔迹逐页隔离。
- 同一控制器支持退出全屏及重新放映。计时暂停/恢复；平板本地翻页同步手机，私密备注不出现在观众画面。
- 字幕调用现有 Core Speech Kit 真识别接口。分段结束后继续采集；带会话、采集标识及递增序号同步，翻页保留，关闭/退出/后台/断线清除。识别错误不会填入示例文字。
- 播放音量作用于平板此应用的 HTML 音视频播放；静音保留之前的音量。它不修改麦克风增益，也不修改系统全局音量。目前六页销售汇报无音轨，实际听感未验收。
- 画笔颜色和粗细独立提交，快速连续调整不会把新颜色覆盖成旧颜色。
- 右上角切换应用保留1200 ms轮换；打开画笔设置时系统返回优先关闭设置。
