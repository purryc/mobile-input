# 手机输入与最新设计同步（2026-10-14）

## 本轮落地

- 同步文本框默认 `inputmode=none`，保留光标、选区与编辑能力。自绘键盘收起、展开和触控板模式均不请求系统软键盘；只有 ABC 菜单里的“系统中文输入”放开。切换目标或后台重新抑制。鸿蒙手机壳通过 ArkWeb `onInterceptKeyboardAttach` 按字段的 inputmode 决定是否使用系统键盘；配对和独立参数表单不被封锁。
- 对照 Figma `1552:38914` / `1543:38028`，唯一输入框里新增 48 px 玻璃意图入口。颜色显示实际色点与“调整颜色”；画板、相机、文档使用独立图标。明确点击才打开，识别、普通同步和重连均不自动弹出工具。
- 文本来源范围、任务、目标代次、输入版本独立记录到意图描述；仅稳定文本／完成识别生成建议，删除或否定来源后移除建议。既有确认草图和材料不删除。
- 画板右上关闭、右下确认，关闭保留原始笔迹；确认只采用附件。任务切换后可重新从入口打开原笔迹。文档面板选择内置文件，确认后才加入当前任务；相机入口沿用真实采集与原任务归属保护。
- 颜色合法修改继续即时生效；不新增完成步骤。关闭后保留参数，手动调色优先于同一任务的识别结果。
- 对象修改一次明确发送后直接修改并保存平板文件，保留目标、草稿、工作副本和已保存版本校验及命令去重。手机不再显示修改前后／应用修改。格式控件即时写入同一 Office 文件，文字要求仍需发送。旧预览数据不会重放执行。
- 共享输入区继续使用 `1493:55578`；更新截图工具图标，键盘展开态语音为图标，保留无障碍名称。颜色、手绘、文档壳层使用透明玻璃，阅读区域保持更高不透明度。短窗口下工具区压缩滚动；展开键盘时临时让出工具区域，收起键盘恢复原面板。
