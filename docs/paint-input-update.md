## 最新交互调整

用户在真机识别成功后要求“直接执行，不用再确认”。因此明确的单一“新建图层／切换涂抹／切换液化”在识别成功结束后执行一次；部分转写、错误、取消、标点、否定或多动作表述不自动执行。无法匹配时显示支持的操作。文本焦点下仍只听写。

## 实施与保存

- 普通字段增加应用、对象、焦点代次、内容版本、来源和序号。并发时保留两版，明确采用平板或恢复手机内容；微信、弹幕和 Agent 提交仍显式执行。Office 文件保存规则不变，字段实时同步不等于保存文件。
- 新增独立绘画状态。首次迁移备份到 `mobile-input:paint-backup-v1`，旧画作保存在“我的画作”，标题菜单可切换“海边速写”；笔记数据保持独立。
- 六种笔触使用不同线条、透明度、纹理及合成方式。涂抹沿路径混合像素，液化局部推移像素；一次完整手势一次撤销。单作品保留 30 步历史，每层最多 600 次操作、每手势最多 2000 个采样点。达到状态容量上限时拒绝并显示原因。
- 无焦点不显示文本框，未知焦点或断线保护未确认写入内容。语音、剪切、粘贴均绑定原目标；旧转写不能进入新字段或改作命令。
- 收到仅标点/空白的识别结果不改正文、不显示绘画菜单；显示未识别到文字。通用输入采用手动结束录音，WPS 字幕保留原有分句机制。
- 没有新增手机照片导入绘画，采集继续走原有任务材料流程。
