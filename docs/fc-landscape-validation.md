# FC 横屏手柄

设计依据：[Figma 游戏区](https://www.figma.com/design/ApFLno64NcMoA17MiPFfZh?node-id=109-5273)，主画面 `5:10639`，844×390；暂停 `5:10817`，断线 `5:10915`。

## 实现

按设计保留左侧十字键、中间三条装饰线及 SELECT／START、右侧斜排 B／A、顶部连接状态及应用名称。右上角 48×48 的独立按钮调用原有应用轮换；每次推进一格，平板显示列表，停顿 1200 ms 后进入。应用标题本身不再承担切换入口。

手机 HAP 进入 Mario 时调用原生窗口横屏，退出恢复 AUTO_ROTATION。浏览器竖屏保持横屏画布比例并旋转呈现；横屏按可用空间等比缩放，保留安全区。ResizeObserver 在旋转时释放已按住的按键。

方向、A 跳跃、B 加速支持多指组合。切换动作沿用协议中的原子清键和暂停，保留连续轮换；不会额外发送会取消轮换的 release 命令。右上角处理非主触点的 pointerup，避免按住游戏键时另一根手指点击被漏掉。START 暂停／继续，SELECT 长按一秒重开；松手、取消、后台、断线及退出取消长按计时并释放按键。第一关地面路线中上下方向只有按压反馈，游戏引擎使用左右、跳跃和加速。

图标、方向底盘、按钮反光均为 Figma 原始导出 SVG；本地 Noto Sans SC 500／700 为控制器文字子集，附 OFL。来源、文件大小、SHA-256 和 SVG 根尺寸在 `reference/fc-figma.json`。静态截图只用于对照，不进入应用界面。玻璃底色按截图校准透明度，未宣称像素完全一致。
