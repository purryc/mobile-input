# 手机独立 ChatGPT 授权与真实润色

更新：2026-10-14。最终选择为 ChatGPT OAuth；Gemini 和 Mac 代理方案均未接入，未使用环境中的 Gemini API key。

## 使用

手机右上角连接设置 → AI润色 · ChatGPT → 使用 ChatGPT 继续。系统浏览器中登录并授权后，返回 Input Agent、恢复平板连接。选中文字或直接在当前文本框点击当前场景对应的润色 action。请求只包含该选区或字段；没有发送聊天、创建任务或提交文档的隐式行为。成功替换后可撤销。等待时可取消，继续编辑会取消旧请求。

手机直接连接 OpenAI，不需要 Mac 服务。双设备输入仍需局域网连接；真实润色另外需要手机能访问 OpenAI。普通浏览器开发版不含账号令牌或可用模型回退，自动化通过原生适配器模拟接口验证生命周期。

## 授权与协议

- 官方动态公开客户端注册，系统浏览器 + 127.0.0.1:1455/auth/callback；state、nonce 和 PKCE S256 每次随机生成。回调只监听手机回环地址，超时／取消关闭，不把授权页面放进应用 WebView。
- 使用官方 JWKS 校验 ID Token 的 RSA 签名，并验证 issuer、audience、nonce、到期及返回账号身份。保留已分配的 client ID，避免代码交换失败后遗失注册。
- 手机原生私有文件保存主机身份、注册及授权；临时文件写入并 fsync 后原子重命名。令牌不传给 Web、平板或 Mac，不进入 Git、HAP、交付包与日志；未启用云备份接口。
- 访问令牌到期前刷新，并同时保存轮换的 refresh token、权限与到期。注销、取消或新登录代次使旧异步结果失效。账号切换须先退出，再重新授权。
- 授权后读取账号可用模型，优先 gpt-6-luna，再选可用的文字模型；不以硬编码目录冒充账号权限。
- 使用官方 /v1/responses，store=false、stream=true；只有收到有效 response.completed 和正文才替换文本。中断、incomplete、refusal、错误或工具输出均不当作润色成功。没有自动重试或独立 API key fallback。
- 前端绑定目标、焦点代次、字段版本、原文和选区。等待期间继续编辑、切换目标、断线或后台均拒绝迟到覆盖。成功替换进入原有撤销历史。

## 按场景推荐润色 action

三个入口保留在原编辑区底部，按实际应用和文本对象在本地选择。切换目标更新推荐，录音过程中不可触发；只在点击后调用 GPT，无额外的推荐网络请求。新任务不预设产物类型，对象指令仍是指令润色，不执行对象任务。

| 场景 | 默认 action |
| --- | --- |
| 微信回复 | 自然回复／更礼貌／简短回复 |
| WorkBuddy 任务和对象指令、豆包输入 | 说清需求／整理要点／精简指令 |
| 邮件正文 | 商务表达／说清诉求／精简表达 |
| 文档正文 | 规范表述／精简表达／修正语病 |
| 幻灯片标题 | 标题清晰／精简标题／修正语病 |
| 幻灯片内容 | 提炼要点／精简表达／规范表述 |
| 演讲备注（文本编辑目标） | 口语讲述／提炼要点／压缩讲稿 |
| 笔记 | 理顺笔记／提炼要点／精简表达 |
| Bilibili 弹幕 | 自然评论／简短弹幕／更礼貌 |
| 绘画图层名称 | 清晰命名／精简表达／修正语病 |

数字、无文本焦点和绘画命令不显示润色。演讲／游戏专用控制器不额外添加文字区。共用原生 allowlist 指令，未知 action 拒绝执行。保留旧版三种 action 的桥兼容，但新版界面只显示场景推荐。

新增场景映射测试与原生指令 allowlist 检查；103 项核心测试、3 项浏览器回归通过。手机已覆盖安装并重新配对；ChatGPT 授权保留，WorkBuddy 真机显示“说清需求／整理要点／精简指令”，没有替换用户当前草稿。前一修复版真实模型调用已通过；本次新增 action 的映射和请求通过自动化验证，未逐个发起真实调用。
