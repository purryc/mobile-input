## 实现覆盖

| 设计 | 本地原型实现 | 边界 |
|---|---|---|
| 句内参数 | 唯一可编辑句子；原词位置的色块、照片、画布、截图、录屏、文件、路径参数 | 原始文字与显示标签分开；不把 UI 标签、缩略图或 HTML 写进任务 |
| 两态与尺寸 | Suggested / Default；32 px 标签、48 px 点击行、自动换行、选中描边 | 内部继续保留来源、任务、版本与手动选择优先级 |
| 单一辅助区 | 点其他参数替换；点当前参数或关闭收起 | 不清除颜色、笔迹或材料，不自动确认或发送 |
| 弹性中部 | 无控件时文本框填满；展开时独立滚动，发送及输入 dock 固定 | 小屏与键盘展开时正文可滚动，不裁掉原文 |
| 手绘 | 空白画布、实际笔迹、确认后原位缩略图、重开及移除 | 不把设计稿示例笔迹当作用户内容 |
| 采集 | 截图预览；录屏先选择再手动开始；原生相机继续走原目标保护流程 | 仅采用后绑定任务；取消不上传、不发送 |
| 文件 | 选择内置文件，路径保留全值、显示 basename | 不声称任意本地路径可访问，不增加真实文件导入 |
| Scope / Format / Template / Size / Count | 稳定明确文本解析与轻量参数选择 | Figma 本次只提供 token 变体；选择面板复用原型表单样式。配置表达任务要求，现有确定性演示执行器不等于完整文档转换/批量生成服务 |
| 编辑与语音 | 与原文本框共用光标、选区、中文系统输入、自绘键盘、emoji、剪贴板、撤销、润色及语音桥 | 浏览器模拟事件只验证路由，真实 ASR 单列验收 |

未引入 Jev 或新模型调用；规则、推荐与任务执行继续本地运行。Gemini 只用于用户明确点击的文本润色。

- 保留平板权威文本、逐任务输入版本、命令去重、断线保护、迟到语音和润色拒绝规则。
