# 小艺Work全控件输入示例

设置→显示调试控件，默认关闭。每个示例创建独立草稿。也可直接复制下列整段；段内没有空格或换行。

## 明确意图

```text
请为客户成功团队准备一份桌面协作助手的新品上手培训演示。先说明产品价值和适用客户，再介绍创建工作空间、邀请成员和协作整理资料的流程，最后总结常见问题与使用建议。演讲时长设为10分钟，主题色用蓝色，背景用白色，文字用黑色，字体用微软雅黑。配色方案选择沉静专业，页面颜色以我明确指定的值为准。参考文件选择内置产品介绍，上下文来源选择ima知识库中的产品资料。我会上传产品图片，并提供纸质培训提纲的扫描件作为内容参考。第二页的布局以我接下来绘制的手绘草图为参考。我会提供一张工作空间页面的参考截图，供你参考视觉样式；再提供一段邀请成员流程的参考录屏，供你参考操作顺序和过渡效果。使用演示设计专家，选择演示文稿制作技能。输出格式选择PPT和PDF。
```

## 模糊推荐

```text
请帮我准备一份简短的演讲报告，用来向客户成功团队介绍桌面协作助手。希望新同事听完后能讲清产品价值，并带客户完成第一次团队协作。内容需要涵盖适用客户、创建工作空间、邀请成员、整理资料和常见问题。整体希望沉静专业，标题有重点，页面明亮，正文清楚易读，字形适合培训投影，请帮我搭配。内容需要可靠的产品资料支撑，也希望补充已连接资料来源中的相关知识，请推荐合适的参考材料和上下文来源。希望大家能直观看到产品实际的样子，我手头还有纸质培训提纲，想把里面的内容提供给你参考。第二页的排版想法用文字不容易说清，希望有方便表达布局的方式。我还想把现有工作空间页面的视觉样式，以及邀请成员时连续的操作步骤和过渡效果，提供给你作为生成参考，请推荐合适的材料入口。这份培训需要专业人士把关，也需要合适的制作能力来完善呈现。交付时希望有一份可以继续编辑，也有一份方便直接分发和阅读。
```

## 混合意图

```text
请为客户成功团队准备一份桌面协作助手的新品上手培训演示。先说明产品价值和适用客户，再介绍创建工作空间、邀请成员和协作整理资料的流程，最后总结常见问题与使用建议。演讲时长设为10分钟，主题色用蓝色，背景用白色，文字用黑色，字体用微软雅黑。整体希望沉静专业，请推荐适合的配色方案，其余页面装饰与我指定的颜色协调。希望有相关产品资料支撑内容，请推荐可用的参考文件，并从已有连接器中推荐合适的上下文来源。我会上传产品图片，并提供纸质培训提纲的扫描件。第二页布局以我接下来绘制的手绘草图为参考。我会提供工作空间页面的参考截图，供你参考视觉样式；再提供邀请成员流程的参考录屏，供你参考操作顺序和过渡效果。使用演示设计专家，选择演示文稿制作技能。输出格式选择PPT和PDF。
```

每组覆盖13类句内控件及底部AI润色。明确意图均为普通chip；模糊推荐均为推荐chip；混合意图仅配色、文件、上下文来源为推荐chip。材料入口不等于附件，图片、扫描、草图、截屏和录屏均需手动提供并确认。内置产品介绍是随项目打包的真实虚构示例文件。ima及专家、技能为演示选择，不连接或执行外部服务。录屏可保存为参考材料，当前生成接口不支持视频，带录像发送会提示移除。

## 逐控件预期

“普通”包含用户明确值和材料选择入口；“推荐入口”不带虚构材料。相同类型的截图与录屏共用屏幕参考材料浮层。
