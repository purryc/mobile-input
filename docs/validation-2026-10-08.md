# 双设备微信、Hover 页面与 FC 游戏验收

日期：2026-10-08。本记录覆盖本轮实现，历史记录保留在 validation.md。

## 已实现

- 桌面七个入口，清洁品牌图标、Mario 图标与无 Dock 布局；WPS 文件首页支持新建和已有文件。
- WeChat 复用 Hover 陈总、老婆、Alex 会话与一家人样例。消息智慧圈、手机两条建议和最多三个动作；输入框独立激活。
- 按会话保存草稿、手机编辑实时同步、快捷回复直接发送且不覆盖独立草稿。正式发送原子携带全文；旧对象、旧序号、重复命令受保护。
- 全选、复制、剪切、粘贴、完整 emoji 删除、撤销、重做；本地预置 Polish。手机语音调用真实 Core Speech Kit，没有预设转写文本。
- 导入 Hover 已有 Sheet、编辑页、结果页和全屏模拟页，14 个应用类型、16 组动作映射；来源和改动记录在 reference/hover-import.json。
- 日历及所有第三方页面均为本地演示。表单按会话＋消息＋动作隔离，字段与选项保留。酒店“先别订”、邮件“先存草稿”、缺失来源与更正消息保持约束。
- 家庭群原始样例没有已实现的动作映射，保留聊天和回复，不增加虚构推荐入口。未实现规则条目不生成入口。
- 仅平板显示七格轮换，每次下一项，1200 ms 自动进入；取消与过期计时器保护。返回逐级退出 Sheet 编辑、详情、文件和会话。
- 固定版本 Mario JS、本地资源与地面第一关；手机 FC 组合键、A 跳跃、B 加速、START 暂停、长按 SELECT 重开。

## 真机证据

- 平板 MRDI-W10（API 24）、手机 SUP-AL90（API 26）两端专属签名构建成功。
- HDC 对两个 signed HAP 均返回 install bundle successfully；启动均返回 start ability successfully。
- 已停止电脑 5188 Web 服务和 5190 静态服务，5189 桥也未运行；两端仍显示天生会画／当前画布及连接状态。USB 仍连接用于取证，不视为拔线验收。
- 手机自动发现平板局域网地址，输入六位码配对后两端显示已连接。电脑 5189 调试桥当时未运行。
- 平板选择陈总会议消息后，手机显示相同消息和三项推荐；手机已打开 Hover 日历半屏 Sheet。证据：phone-hover-calendar-device.png。
- 手机输入 LAN-draft-1008，平板回复框同步显示全文；正式发送前仍为 textField，未成为聊天消息。
- 用户在本轮对话明确反馈：手机真实语音已“出现了识别文字，可以编辑”。这是用户操作确认；未单独量化准确率。
- 手机原生剪切后字段清空，经 PasteButton 粘贴后恢复 LAN-draft-1008。对应 phone-paste-layout.json 可核对。
- 普通调试签名声明 READ_PASTEBOARD 会被安装器拒绝（9568289）。已移除该受限权限，使用系统安全粘贴控件；未扩大签名权限。
