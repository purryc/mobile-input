# 统一手机控制器 · 2026-11-03

本轮已获准更新并安装两端；不修改 Figma，不推送 GitHub。真实鸿蒙应用保持未接通，不复用演示状态冒充可用能力。

## 结构

- `packages/core/phone-controller.ts` 定义按应用、场景和能力归一的快照、任务身份与任务操作接口。
- `phone-control-adapter.ts` 从平板权威状态或 Mac 桥接读取设备、会话、目标、任务、材料和执行状态。鸿蒙真实应用返回不可用快照。连接目的地只选择数据源。
- `PhoneController` 作为统一入口；`PhoneControllerFrame` 统一身份区、任务条、主题及固定底栏位置。WorkBuddy 普通任务、网页演示、审批、材料和对象编辑均接入；Codex/WPS 的 Mac 控制器复用外壳。专用播放、游戏保留专用控制。
- `agent-input-view.tsx` 提供共享 Composer、辅助面板、颜色、时长和手绘组件。Demo 与 Mac 的原生选择器、文件传输、生成与真实提交仍由原有适配器处理，视觉层不直接写目标。
- `ContextualPolishActions` 继续是 Composer 外同级控件；InputDock 是底栏几何的唯一所有者。

## 任务和主题

任务按 ID 去重，保留同名不同任务；当前任务不再额外重复一张标题卡。新建入口固定，列表独立横向滚动。新任务首页保留已有任务。Mac 只采用可可靠确定的 AX 选中身份或唯一标题匹配，不推测运行状态。

主题读取现有 `liquid-glass-tokens.json`：WorkBuddy 青绿色，Codex 中性，WPS 依子应用。连接方式和正文色彩参数不改变主题。普通任务也支持句内颜色、时长、草图与材料；明确发送 PPT 要求后才进入平板 Gemini 生成，不因采用或切任务创建生成工作。

## 保留与边界

保留原有任务及材料归属、按目标版本验证、原子提交、未知结果不重放、共享底栏手动偏好、语音与 USB 自动重连。任务切换先结束录音并等待当前编辑队列。普通任务的旧版附件/草图走兼容内容分支，外壳与任务条一致，不丢弃旧数据；审批/材料请求仍使用专属内容。

同一原生构建代次升级按项目既有规则一次性重置演示数据；保留原生配对、权限、密钥及真实 Mac 数据。
