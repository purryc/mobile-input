### 预设交互路径

1. 01 点击更多 → 02；在弹层长按任一操作 → 03。
2. 03 拖出“分享链接” → 04a 抓起 `1924:96327` → 04b 拖离弹层 `1924:96358` → 04c 邻键让位 `1914:94971`；松开浮起按键或点击落点 → 04d 落位 `1924:96857` → 04e 末键缩入更多 `1924:97061` → 05。未放下前点击空白区或 Escape 返回 03，恢复原顺序。
3. 05 完成 → 06；再次打开更多 → 07，首位显示被挤出的“字数统计”。
4. 06 长按 → 08；拖动“保存” → 09 移至首格；完成保留这份顺序。
5. 09 拖动“书签” → 10 移回更多；完成 → 12；打开更多 → 11，首位为书签。
6. 返回分组时取原更多首项回填主面板末位，保持十一项直接操作；排序和材料不丢失。
7. 13–18 为原始整理、完成及继续整理弹层的必要返回状态。正常关闭只关弹层，整理中关闭弹层仍留在整理状态。

## 结构约定

- 在控件库 2:2 新建独立测试 Frame，内含标准手机的收起底栏、展开触控板，以及紧凑手机布局；控件源放在同一测试区。
- 复用 Liquid Glass 原子动作控件、字体、图标与固定底栏。九键是 3×3 上限，更多占一格，固定编辑键不重复。
- 390 px 手机：18 px 边距，354 px 网格，8 px 间隔，112.67 × 72 px 单键。标签最多两行；按下期间不重排。
- 触控板展开后仍用 368 px 共享底栏。紧凑高度优先保持底栏触控尺寸，业务键收为两行（含更多）；不同状态独立 Frame，仅用于空间测试。
- 示例名称属于布局占位，不表示应用命令已接通。无有效文本目标不生成文本框。任意生成仅指登记动作的场景组合，不生成任意执行代码。
- 检查单键触控范围、长中文换行、网格边界、与底栏的间隔；不据静态设计声称真机操作效率。
