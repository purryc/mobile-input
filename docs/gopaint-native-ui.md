# 天生会画平板界面复刻修订

## 参考与实现范围

本轮直接打开 MRDI-W10 的天生会画 `com.huawei.hmos.hicreate`，版本 **16.0.0.235**，采集 2800 × 1840 的画布、图层、笔刷库、调色和滤镜面板。以设备当前安装版本为主；华为官网的[界面介绍](https://consumer.huawei.com/cn/support/content/zh-cn16041995/)、[图层](https://consumer.huawei.com/cn/support/content/zh-cn16042001/)和[画笔工具](https://consumer.huawei.com/cn/support/content/zh-cn16041991/)补充功能位置。

原生截图包含用户自己的画作，只保存在忽略的 `reference/private/gopaint/`，不会进入 Web、源码交付包或 HAP。运行界面全部为 React / CSS / SVG 和实际图层缩略图；来源、尺寸、截图哈希见 `reference/gopaint-native-ui.json`。没有修改原生画作内容。

## 对照覆盖

| 区域 | 原生参考 | 本轮实现与边界 |
|---|---|---|
| 画布 | 全屏、工具悬浮 | 移除原型系统栏、窗口栏、大横排工具栏及常驻侧栏；保留现有画作等比显示 |
| 左工具栏 | 笔刷、涂抹、橡皮、流体笔；双竖滑杆 | 同布局深灰胶囊；现有液化占第四工具位；大小 1–40、不透明度 1–100 实际影响笔迹 |
| 编辑胶囊 | 撤销、重做、操作、选区、变换、滤镜、图层、颜色 | 按原顺序复刻；选区和变换明确禁用；滤镜只有已实现液化；右侧为连接按钮让位 |
| 图层 | 悬浮圆角列表、蓝色选中、缩略图、可见性 | 默认收起；真实缩略图、选择、隐藏、新建、改名、文本编辑；背景行只展示白底 |
| 笔刷库 | 左分类、右笔触卡片、搜索 | 分类、搜索、收藏、五种现有画笔可用；未接原生全量资源和导入 |
| 颜色 | 色盘／色环／滑块／色卡，HSV、Hex、历史色 | 四视图可用；调色即时同步；橡皮禁用颜色入口 |
| 返回与连接 | 原生左上返回 | ≥48 px 返回逐级关闭面板；保留右上 Input Agent 连接，不绘制系统手势栏 |
| 手机 | 已确认 Figma 控制器 | 维持现有布局与自动语音命令；文本目标、图层数据和撤销链不重置 |

比例以原生截图测量，并作触摸区域和连接入口适配，**不宣称逐像素完全一致**。没有接原生 GoPaint、导入原生文件、云服务或完整专业画笔引擎。
