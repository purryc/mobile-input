# 光标、语音插入与智慧语音主题修正 · 2026-11-04

## 修改范围

- `use-phone-editing.ts`：连续听写固定开始时的光标/选区，累积转写替换同一片段；结束后停在插入文字之后。下一次听写先读取当前光标。共享位置恢复等待正文渲染，并验证目标与文本，避免过期动画帧恢复旧位置。
- `sentence-composer.tsx`：根据正文实际变化映射保留位置；Chip 重绘、失焦和粘贴不把位置复位。用户原生输入已改变 DOM 时不重复移动光标。
- `text-selection.ts`：统一 UTF-16 范围、插入/替换后位置及参数投射的双向范围映射。中文、emoji、多个独立颜色及数字时长使用相同规则。
- `phone-agent-editor.tsx`：同步文字时同时发送对应 Mac 正文的光标/选区；颜色和时长转换后仍指向正确位置。无本地写入或听写占用时回读 Mac 的真实选区，不用旧回显覆盖本地正在输入的内容。
- `phone-mac.tsx`：其他 Mac 文本目标沿用同一位置及选区回读规则。
- `agent.swift`：Codex 的 AXValue 写入会导致光标回到 0，AXSelectedTextRange 设置即使返回成功也无法修正。真机验证改用已确认编辑器的原生输入事件后，可设置并回读真实选区。现使用已验证焦点内全选、临时剪贴板输入并恢复剪贴板、随后设置预期选区；文本和选区都匹配才确认 Codex 写入成功。操作只修改已绑定的任务输入框，不执行 Send/Queue/Steer。
- `protocol.mjs`：验证可选 UTF-16 范围，拒绝负数、小数和超出正文长度的请求。
- `input-dock.css` / `phone-controller-frame.css`：待机、按压和录音态使用同一应用主题，去掉默认录音绿。Codex/ChatGPT 中性，WorkBuddy 青绿，Gemini 品牌主题；共享尺寸及手势不变。
