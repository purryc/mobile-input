## 运行行为

三种模式互斥，点当前模式收起，切换不改草稿。键盘回车只插入换行。ABC 选中后再点击展开输入法菜单，可使用系统中文输入；进入系统输入时收起自绘键盘。自绘键盘开启期间 textarea 使用 `inputmode=none` 防止重叠。保留原有语音手势、编辑选区、采集与鼠标指令。

手机安全区由现有原生内边距处理。窄屏适度缩小横向留白，中部独立滚动；未加入仿制系统栏。
