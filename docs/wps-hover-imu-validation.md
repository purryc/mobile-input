## 实现

- 桌面与应用轮换进入 WPS 时，固定打开销售演示编辑页的第1页，计时00:00；从WPS文件列表打开演示同样从第一页编辑。恢复本地应用状态也回第一页编辑。
- 点手机全屏或平板放映后才播放。退出全屏保留控制器；返回仍经过编辑页、WPS首页、桌面。

- 进入画笔模式即启动真实姿态采集，在平板显示笔形悬停光标。按下才创建笔触；抬起完成笔触并继续悬停，保持校准位置。每次再按下创建独立笔触，不跨越悬停路径连线。
- 笔触按下/抬起有独立递增序号、姿态会话、页码检查，旧事件不能重新落笔。翻页、切换、后台与断线释放旧追踪；画笔翻页后用新传感器事件重新建立悬停。
- 色彩、粗细、撤销与清空保持悬停，但结束正在进行的笔触。

## IMU 映射

旧算法以相对四元数的Y轴偏航作为横向控制。现在旋转手机顶部的 +Y 射线，按屏幕朝上、顶部指向平板的握法计算朝向：相对X向右，Y向前，Z向上。顺时针转向右，抬高顶部向上；沿手机长轴侧翻不作为横移。

水平和垂直增益均为 `1.30 / (π/3)`，相同角度下比原60度全跨度增大30%。采用校准基准的相对四元数，保留30Hz限速与平滑。每次激活画笔或激光重新归中；普通按下/抬起不重新校准。

这里只测量朝向，不通过加速度积分推断平移距离。平台传感器参考：[Huawei Sensor overview](https://developer.huawei.com/consumer/en/doc/harmonyos-guides-V14/sensor-overview-V14)。
