# 固定输入区：共享组件与手动开合

PRD 对应：https://app.notion.com/p/3f9194db24c381bf8b76c804062303e3

## 现行产品规则

- 默认桌面、微信、邮件、笔记、豆包、WorkBuddy、Bilibili、天生会画共用一个 InputDock。场景只传主题颜色 token、有效目标与操作能力，不覆写内部布局、隐藏文字或改按钮顺序。
- 固定底行始终为左侧模式切换、中间当前模式操作、右侧带图标和可见文字的智慧语音。收起、键盘、触控板、开始／录音／识别状态保持相同位置和触达区域。最新修订移除取消录音按钮、浮层及录音状态说明，按钮始终显示“智慧语音”，仅用选中态表示开关。390 px 下语音键为 96×56，触控板展开区保持 368 px。
- 语音支持点击开关和超过 300 ms 按住说话，松开停止；录音中再次按下停止，不因后续释放／click 重启。原生采音成功开启和关闭分别短震动一次，当前为 25 ms；失败开启、重复结果不产生额外震动。不可用的振动硬件不阻断转写。系统手势取消和生命周期保护继续保留，普通停止不提交。
- 触控面短时轻点操作大屏当前光标下的对象；近距离连续两次轻点产生正常点击与双击语义，支持有效文本对象选词。滑动、长按、双指滚动、按键拖动、取消或断线不产生额外点击。此能力作用于复刻应用，不代表系统级第三方鼠标注入。
- 键盘／触控板互斥。用户手动展开后，由用户再次点击当前模式收起，或明确切换另一模式；切任务、新建任务、切对象、返回成果、发送、同步、后台恢复及断线重连均不自动关闭。
- 手动模式偏好属于本次手机输入会话，独立于任务草稿、对象版本和组件生命周期；切任务继续使用该模式，但释放旧按键和旧手势，后续输入绑定新目标。切换游戏／演讲专用控制器临时隐藏通用面板，返回恢复偏好。
- 从未手动选择时才应用默认桌面／成果页自动展开规则。系统中文输入须主动打开；换目标或后台收起系统键盘，恢复先前自绘模式，不自动唤起原生输入法。重新启动手机进程仍需重新启用输入会话。
- 保留最新位置合并、按钮边界顺序和紧凑鼠标回执；文字发送、任务提交与审批仍是明确动作。

## 验收

1. 各共享场景在 390×844、390×700、360×700 下，三种模式的语音文字可见、布局一致，暗色主题仍可读。
2. 轻点可打开实际入口，双击可选词；移动后抬手、取消、双指及后台不误点。
3. 手动展开键盘／触控板，切换普通、票据、材料任务与成果选区后仍展开；手动关闭后不被重新自动打开。
4. 断线／后台停止远端控制但保留模式与草稿，恢复核验目标；不补发旧点击。
5. 浏览器、构建安装和真机结果分别记录；未验证项不得写成通过。
