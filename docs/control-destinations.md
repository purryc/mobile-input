## 执行契约

配对与控制目标分离。只有认证后的当前连接可请求状态。切目标停止旧控制、释放按键、作废待回执，不把旧草稿自动写入新目标。恢复只读取，不重放操作。手机输入走唯一编辑区；普通 AX 可读写文本即时同步并读回；不可可靠读写的正文只提供明确的插入动作，标明限制，不能冒充同步。Codex 提交必须明确点击，WPS 保存独立点击。

Mac 每次执行核对前台 bundle、窗口、焦点代次以及内容基线；未知窗口/密码框不接入。不通过收到命令或快捷键注入推断业务成功；报告 verified / executed / unknown。格式快捷键无状态读回时保持中性按钮，不显示假字号或颜色。WPS 依据实际子应用身份取主题，未知使用 System 回退。

重置演示只影响副本；不清理真实 Mac 文档、Codex 聊天或系统剪贴板。局域网个人试用需可信网络，Mac 停止 companion 即撤销控制。不使用 ChatGPT/Gemini 凭据连接 Mac。
