# WorkBuddy 信息架构与覆盖矩阵

版本：Input Agent 1.2.0。视觉基线：用户提供的 Work Buddy.mov，WorkBuddy 5.7.7，3050×2000，303.982 秒。检查日期：2026-10-09。录屏、比较帧仅存放在忽略目录；应用中的任务、邮件、文件、姓名全部采用现有虚构销售故事。

## 架构树

```text
WorkBuddy
├─ 新建任务（默认首页）
│  ├─ 日常办公 / 代码开发 / 设计创意
│  ├─ 场景模板 → 填入 → 修改 → 发送
│  ├─ 上下文：附件 / 文本引用 / 技能 / 专家
│  └─ 模型 / 工作空间 / 权限 / 默认、计划、仅问答
├─ 任务历史：搜索 / 切换 / 收藏 / 重命名 / 删除 / 项目分组
│  └─ 任务对话
│     ├─ 用户消息 / 步骤 / 耗时 / 停止 / 继续 / 追问
│     ├─ 计划确认 / 无法映射时选择成果类型
│     └─ 成果卡片 → 分栏预览
│        ├─ 文件目录 / 多标签 / 缩放
│        ├─ 文本选区引用 → 任务上下文
│        ├─ Markdown 编辑 / 保存 / 显式刷新
│        └─ 表格、文字、演示 → 现有 WPS
├─ 助理：列表 / 创建 / 渠道配置 / 本地对话
├─ 专家·技能·连接器
│  ├─ 专家：分类 / 搜索 / 详情 / 召唤
│  ├─ 专家团：角色配置 / 召唤
│  ├─ 我的专家：创建 / 修改 / 删除
│  ├─ 技能：推荐 / 分类 / 搜索 / 安装 / 移除 / 已安装
│  └─ 连接器：分类 / 详情 / 工作空间配置 / 启用 / 停用
├─ 定时任务：创建 / 编辑 / 日期时间 / 启停 / 试运行 / 记录
├─ 资料库：最近 / 文件夹 / 搜索 / 内置销售资料 / 预览 / 引用 / 删除
├─ 项目（录屏的“空间”）：创建 / 指令 / 资料 / 任务 / 成员
├─ 发现应用 → Buddy 销售工作台：本地授权 / 场景 / 专家配置
├─ 更多：我的邮箱 / 腾讯文档 / 知识库 / 灵感
└─ 设置与辅助：账号 / 用量 / 模型 / 权限 / 记忆 / 数据导出 /
   菜单排序 / 消息中心 / 多端协同
```

手机 IA：待机桌面 → 平板显式聚焦编辑对象 → WorkBuddy 输入页（应用连接状态＋切换入口、任务与引用上下文、编辑工具、草稿、AI润色、固定语音按钮、发送／保存）。平板导航、菜单和预览始终在平板操作，手机负责当前目标输入。

## 官方来源与检索边界

- S1：[官方导航文档](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Sidebar)。导航层级同时在成功读取的 Task-Bar、Expert-Center 和 Skills-Market 文档中交叉检查。Sidebar 本轮单页访问超时，不将超时页面正文作为已读证据。
- S2：[新建任务栏](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Task-Bar)。核对任务独立性、三种模式、模板点击填入、工作空间与模型配置。
- S3：[专家](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Expert-Center)。核对专家、专家团、分类召唤与我的专家管理。
- S4：[技能](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)。核对市场、搜索、安装／卸载及新版启用开关。
- S5：[Buddy 应用](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Buddy-App)（本轮官方搜索摘要）与[开放平台 Buddy 配置](https://open.workbuddy.cn/docs/buddy-app)。工作台聚合行业场景与能力配置。

## 新旧差异与视觉测量

- 5.7.7 侧栏为“定时任务”；新版文档称“自动化”。原型保留录屏名称，行为仅前台本地定时。
- 录屏项目归于“空间”；原型新增可操作“项目”列表，保留空间中的分组入口。
- 新版技能文档有启用／关闭与卸载分离。本轮保留已批准的安装／移除范围，启用细分登记为新版差异。
- 新版文档增加云服务、Git 并行开发、项目 Slash 命令、聊天转发、长文本折叠；录屏未覆盖，进入研究附录。
- 侧栏宽为画面约 23.4%；首页输入区约占剩余区域 69%；主内容白色、侧栏浅灰，控件保留紧凑密度，输入框独立圆角。鸿蒙使用真实安全区，不复制 macOS 红黄绿窗口钮、时钟和手势条。
- 布局与图标逐页对照；专家推广卡采用可编辑销售主题图形，文案及人像未复刻私人录屏。不同屏幕比例和字体仍有差异，不宣称逐像素一致。
