# 各应用固定键以外的适配清单

2026-10-20。以原Excel的新PC H/I列为主，结合K单号与L计划；沿用逐行复核与语义归一结果。仅做研究清单，不改运行时、Figma或原Excel。

扣除固定编辑七键：全选、复制、剪切、粘贴、删除、撤销、重做。对象操作仍需正确绑定；扣除代表无需重复UI，不代表已经实现跨应用操作。搜索、Esc并非所有应用的固定键；文本回车不等于发送/确认。永久删除和删除确认仍独立保留。

支持与规划动作已合并在同一表格：△表示规划候选（有单号未明确排除或明确计划），无△表示表内支持/已完成，均不等于本轮真机验收。新PC I列为空写“键位未填”，原表不完整或方向存疑的键位明确标出，不按Windows/Mac推填。原表没有频次数据，首屏排序均为设计建议。九键包括更多入口，使用更多时最多8个直接动作。

成对动作以括号合写，例如（上一页／下一页）。这只是分组展示：两个独立动作仍需两个点击目标，不能按一个键估算容量；播放/暂停等真实切换命令可以是一个键。

41个有动作明细的应用，扣除后共213个按应用分别计数的语义候选。213不是必须常驻的按钮总数：确认/取消/菜单随场景出现，选择与导航可以由专门输入控件承担。另36个仅有应用名的占位项不能补造功能。
