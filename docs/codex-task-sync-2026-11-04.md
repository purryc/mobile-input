# Codex 当前会话与手机切换修复 · 2026-11-04

已更新手机与 Mac Companion。真实手机任务条切换 Codex 会话、切回原会话通过，原草稿未改变；没有发送任务、修改消息或操作归档。

## 原因及改动

- Codex 当前版本的会话按钮暴露 `AXShowMenu`，没有 `AXPress`。旧切换分支直接调用 AXPress，无法实际激活。现在复用已验证的 Codex 按钮激活：设置并核对该按钮焦点后按 Space，不向正文注入按键。
- 激活调用不等于切换成功。等待有界时间，只有权威状态读回目标会话才返回 verified；未知结果保留保护，不自动重复点击。前台、窗口及输入目标改变继续拒绝旧命令。
- 有界任务列表最多 60 项，现在保留超出首批列表的唯一当前会话；完整候选集中的同名歧义不会因截断而变成“唯一”。不以位置猜测会话身份。
- 共享任务条在权威当前项变化后自动滚到该项；不再让已选项藏在横向滚动范围之外。失败不更新选中项，切换不关闭手动展开的触控板。

修改：`scripts/mac-bridge/agent.swift`、`apps/web/src/phone-controller-frame.tsx`、`scripts/mac-bridge/generic-agent.test.mjs`、`tests/generic-agent.spec.ts`、项目规则与本记录。
