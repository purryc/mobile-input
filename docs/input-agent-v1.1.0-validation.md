# Input Agent v1.1.0 验收记录

日期：2026-10-08。应用版本：1.1.0 / 1001000。两端原包名保持不变。

## 本版变更

两端原生 AppScope 与 EntryAbility 标签、Web 标题及局域网发现名称统一为 Input Agent。连接入口统一为右上角 48 × 48 的图标，手机位于真实系统状态栏下方的应用状态区，平板常规状态栏及全屏覆盖层均可访问。连接与应用切换为独立入口。

共享连接面板提供真实连接状态、手机地址／配对码输入、原生扫码／重新发现，以及平板二维码。面板保留底层编辑器，背景不可操作；系统返回、Escape、关闭或点击遮罩可退出。打开时取消应用轮换、释放游戏按键、停止姿态／录音；返回仍保留文字草稿。

真机检查修正了手机安全区遮挡，并避免触屏按下打开面板后，随后的抬起事件立即误触遮罩而关闭。
