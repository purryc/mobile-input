# WorkBuddy 单机 Web 输入演示

本版将现有手机的动态多模态输入体验放进 WorkBuddy 大屏界面。在一台电脑的 Chrome 内完成语音、句内参数、图片、文件和手绘输入，发送后进入复用平板布局的任务页，通过 Gemini 生成演示文稿、文档和图片，并在右侧打开成果。不会执行真实 Mac Agent 任务。

## 演示流程

1. 点击麦克风图标，说：“做一份产品介绍演示文稿，参考产品资料，主题色用红色，背景用灰色，字体用黑色，讲五分钟，加产品图片，布局我画一下。”
2. 转写过程中，五类入口在原句内出现；再次点击语音停止。也可以键入、粘贴同样的内容。
3. 点颜色修改角色对应的 HEX；点时长调整分钟数；点资料选择文件。参数识别本身不打开面板。
4. 点图片进入「图片选择」。选择本地图片或拍摄后，先在面板中预览，明确确认后才进入附件区。关闭不确认，原句图片入口仍可再次打开。
5. 点布局手绘。画笔、橡皮、撤销和清空均可用，确认后作为图片材料采用。面板关闭保留未确认笔迹。
6. 点击发送，左侧显示冻结后的请求、已确认材料和实际生成阶段，右侧以标签页打开成果。输入草稿仍可继续编辑；历史请求不会被修改。
7. 演示文稿可直接编辑标题/正文/讲稿，调整布局/颜色，增删/排序页面，撤销/重做，点击放映并用方向键翻页；文档可以直接编辑段落，或打开 Markdown 编辑完整原文；图片显示真实返回图像。三个类型均可下载。
8. 也可以新建任务说“写一份产品发布方案”或“生成一张产品宣传海报”，或者在同一请求中明确要多种成果。规划最多三种成果，每种一个；“参考照片／加产品图片”本身不额外生成图片。
9. 生成时可停止；失败显示原因，保留草稿和已经生成的部分成果。点击重试会创建新的请求记录，不覆盖以前的结果。切换草稿时任务继续归属原草稿；刷新将运行中的任务标为中断，不会自动再次提交。

每次「新建演示」都有独立草稿。已确认材料、待确认图片、未确认笔迹及历史记录保存在独立 IndexedDB `workbuddy-standalone-demo-v1`。等待左下角显示「保存在这台电脑」后可刷新。未完成持久化时离页会触发浏览器保护。不同端口/hostname 是不同浏览器存储空间；请固定使用同一个地址。

「清理演示」只清理本版数据库中的演示内容，不清理原项目的数据。材料在选取和确认时保留本机，只有明确点击发送才会随当前请求交给 Gemini。生成支持 PDF、TXT、Markdown、PNG/JPEG/WebP，最多 12 份，每份最多 8 MB、总计 24 MB。旧草稿中的其他格式仍保留，但会阻止生成并提示转换格式。浏览器识别本身可能将麦克风音频交由浏览器语音服务处理；本应用不录制或保存音频。

## 实现边界

- 复用 `SentenceComposer`、`resolveLiveParameters`、`projectTargetInput` 和已有颜色/时长/图片/草图控件，保持原有 source span、作用域、否定识别、手动值和图片明确确认规则。
- `SentenceComposer` 仅增加可选 `label` 和 `inputMode` 属性，手机默认行为不变。
- 单机入口拥有独立状态、存储和 `BrowserDictation` 适配器，不导入 `runtime.ts`、手机配对、Mac 桥接、原生服务或原手机/平板生成执行器；独立本机服务调用共享 `generateDeck` 生成契约。
- 识别结果按单轮累计 results 重建，中间结果可以修订。自然结束在仍开启时续接；空识别连续三次结束后停止并给出重试提示。停止等待最多 1.8 秒；切换草稿/后台取消并忽略迟到回调。
- 录音时点句内控件先收尾再打开，直接编辑立即停止采集并保留已有转写。连续两轮语音在上轮插入末尾续写。停止不会发送。
- 摄像头在关闭、离开页面或采集完成后释放；迟到媒体授权获得的流也立即释放。
- 演示文稿采用平板原有网页幻灯片模型，下载 HTML（内嵌照片，可离线浏览/翻页）；文档下载 `.md`；图片按实际 PNG/JPEG/WebP 返回。没有冒充 `.pptx` 或 `.docx` 文件。
- 本版没有 AI 润色、外部应用执行、设备安装、Figma 修改或云发布。生成页中的编辑为本地直接编辑，不会偷偷调用模型。
- 成果自动保存到同一独立 IndexedDB；编辑有独立的最多 30 步历史。原始发送文字/材料快照保持不变。

## 生成服务配置

开发和生产预览均自动加载 `scripts/workbuddy-demo-service.ts`，不需要另开桥接进程。只接受 localhost/127.0.0.1 同源请求；最多同时处理两个任务，每次最多四分钟，断开请求或点击停止会中止上游请求。

服务端按优先级读取 `GOOGLE_API_KEY` 环境变量、`WORKBUDDY_DEMO_KEY_FILE` 指向的私有文件，或本目录已忽略的 `artifacts/workbuddy-demo/google-api-key`。新机器请使用环境变量或权限为 600 的私有密钥文件。不要在网页、源文件或命令示例里粘贴密钥。本机私有文件不包含在交付压缩包中。

- 文本/演示模型默认 `gemini-3.8-flash`，可通过 `INPUT_AGENT_DECK_MODEL` 配置。
- 图片模型默认 `gemini-3.1-flash-image`，可通过 `WORKBUDDY_DEMO_IMAGE_MODEL` 配置；采用 Google 官方 [Generate Content 图片接口](https://ai.google.dev/gemini-api/docs/generate-content/image-generation?hl=en)。
- `GET /api/workbuddy-demo/status` 仅返回是否配置及模型名。界面展示实际成果使用的模型；权限/配额/网络失败会保留输入并提供重试。
- 服务不把请求或成果另存到服务器磁盘；清理演示只清除本版浏览器数据库，并中止本页运行任务。
