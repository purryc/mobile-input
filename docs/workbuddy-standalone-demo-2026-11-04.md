# WorkBuddy 单机 Web 输入演示

本版将现有手机的动态多模态输入体验放进 WorkBuddy 大屏界面。在一台电脑的 Chrome 内完成语音、句内参数、图片、文件和手绘输入，发送后展示整理好的请求。没有模型调用或真实任务执行。

## 演示流程

1. 点击「语音输入」，说：“参考产品资料，主题色用红色，背景用灰色，字体用黑色，讲五分钟，加产品图片，布局我画一下。”
2. 转写过程中，五类入口在原句内出现；再次点击语音停止。也可以键入、粘贴同样的内容。
3. 点颜色修改角色对应的 HEX；点时长调整分钟数；点资料选择文件。参数识别本身不打开面板。
4. 点图片进入「图片选择」。选择本地图片或拍摄后，先在面板中预览，明确确认后才进入附件区。关闭不确认，原句图片入口仍可再次打开。
5. 点布局手绘。画笔、橡皮、撤销和清空均可用，确认后作为图片材料采用。面板关闭保留未确认笔迹。
6. 点击发送，查看本次请求、HEX/分钟投影和已确认材料。它不会生成 PPT 或执行真实任务。输入仍可继续编辑；历史发送记录保持原快照，材料可下载。

每次「新建演示」都有独立草稿。已确认材料、待确认图片、未确认笔迹及历史记录保存在独立 IndexedDB `workbuddy-standalone-demo-v1`。等待左下角显示「保存在这台电脑」后可刷新。未完成持久化时离页会触发浏览器保护。不同端口/hostname 是不同浏览器存储空间；请固定使用同一个地址。

「清理演示」只清理本版数据库中的演示内容，不清理原项目的数据。文件没有上传；单文件限制为 25 MB。浏览器识别本身可能将麦克风音频交由浏览器语音服务处理；本应用不录制或保存音频。

## 实现边界

- 复用 `SentenceComposer`、`resolveLiveParameters`、`projectTargetInput` 和已有颜色/时长/图片/草图控件，保持原有 source span、作用域、否定识别、手动值和图片明确确认规则。
- `SentenceComposer` 仅增加可选 `label` 和 `inputMode` 属性，手机默认行为不变。
- 单机入口拥有独立状态、存储和 `BrowserDictation` 适配器，不导入 `runtime.ts`、手机配对、Mac 桥接、原生服务或生成执行器。
- 识别结果按单轮累计 results 重建，中间结果可以修订。自然结束在仍开启时续接；空识别连续三次结束后停止并给出重试提示。停止等待最多 1.8 秒；切换草稿/后台取消并忽略迟到回调。
- 录音时点句内控件先收尾再打开，直接编辑立即停止采集并保留已有转写。连续两轮语音在上轮插入末尾续写。停止不会发送。
- 摄像头在关闭、离开页面或采集完成后释放；迟到媒体授权获得的流也立即释放。
- 本版没有 AI 润色、PPT 生成、其他应用、设备安装、Figma 修改和云发布。
