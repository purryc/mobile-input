# Codex Recents 与任务状态 · 2026-11-04

手机 Codex 任务条现使用桌面实际 Recents 的原始顺序（最近到较早），不再采用项目分组列表。状态来自目标界面，未提交真实任务。

## 实现与边界

- `agent.swift` 从已观察的 Recents 按钮所属区域定位唯一列表，按 AX 子节点顺序遍历会话行；不混入项目组或重复别名，不制造更新时间。读取范围是 Codex 当前暴露的 Recents，不宣称包含全部历史。
- 行内 `Working` → 执行中，`Unread` → 有新回复；仅识别该行元数据，不从聊天正文推测。未知行不显示状态徽标或占位行。
- 当前会话的运行标记或 Stop 控件可证实执行中；行内明确的 Need input / Needs input / Waiting for input 显示“需要输入”，优先于同时存在的运行提示。没有界面状态时不补造“就绪”或“已完成”；全局活动提示和正文提及不属于该会话状态。
- 复用共享任务条和中文/英文词典。维持当前项高亮、自动露出当前项、真实切换回执及草稿隔离，不更改 InputDock。
- Recents 无法可靠定位时不拿项目列表冒充。沿用同名歧义、过期目标和未知状态保护。
