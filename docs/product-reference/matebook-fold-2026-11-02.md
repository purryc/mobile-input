阅读结论

这款产品适合需要在移动携带、大屏阅读、桌面输入和手写表达之间切换的用户。评估重点应放在自己的工作资料能否顺畅流转、关键应用能否完成任务，以及折叠形态是否减少了外接设备和窗口切换的负担。单看处理器或屏幕尺寸，无法判断它是否适合作为日常主力电脑。

本文围绕官网当前麒麟 X90 Plus 版本，提供硬件规格、交互方式、鸿蒙协同、使用场景和购买核对方法；末尾附六页产品介绍 PPT 提纲及可改写的演讲稿，可作为 WorkBuddy 的参考文件。

三条产品主线

第一条是可变化的工作空间：携带时折叠，稳定桌面上展开，阅读、输入、展示可以采用不同的屏幕组织方式。第二条是多种表达方式：键鼠承担精确编辑，触控承担直接选择，适配手写笔承担批注和草图。第三条是设备协同：让文件与输入在受支持的鸿蒙设备间流转，但每项能力仍有自己的连接条件。

资料口径

标注“官方规格”的数值来自官网当前页面；“场景分析”和“演示建议”是本文对实际工作流程的组织，不是性能测试。本文未开展该机型的续航、性能、书写延迟或网络可靠性实测。软件能力以具体机型、安装版本及账户可用状态为准。

本文不把 Input Agent 或 Mac WorkBuddy 的原型功能列为华为电脑自带能力。文中示例演讲、客户沟通与创作流程仅用于说明使用方法。

# 折叠形态与桌面组织

展开时把面积用于对照

官方规格给出的展开屏幕对角线为18英寸，折叠后每半屏为13英寸，均按标准矩形计算，实际可视区域略小。[S1] 面积变化的使用价值，在于能同时看见更多上下文。例如左侧放产品资料，右侧编辑演示；或上方放研究原文，下方写自己的摘要。

建议先确定主任务，再安排辅助窗口。把需要持续阅读的资料留在稳定位置，把频繁修改的内容放在便于操作的一侧。窗口更多并不自动等于效率更高，重复、过小或被遮挡的窗口仍会增加注意力切换。

折叠时把两部分分工

可以把折叠形态理解为一块连续屏幕上的不同工作区域，而不是默认两台相互独立的显示器。上半区看内容、下半区输入或操作，是一种直观的任务分工；具体是否自动出现适合的双区布局，取决于系统和应用适配。[S2]

| 工作方式 | 屏幕组织建议 | 现场核对 |

| 长文阅读 | 主要文档与笔记并列 | 字号 舒适视距 滚动是否顺畅 |

| 内容编辑 | 画面预览与工具区分开 | 工具是否遮住关键内容 |

| 客户讲解 | 放大主要画面 减少杂项 | 对方能否看清 数据是否脱敏 |

| 移动整理 | 保留当前任务与最少辅助窗口 | 桌面空间和输入姿势是否合适 |

支架与放置

官方外观指引对横向展开使用给出具体放置方式：屏幕完全展开，背部支架打开到最大角度，摄像头朝左，放在水平桌面。[S3] 使用时应先保证支撑稳定，再安排键盘、鼠标和线缆。不要从可折叠推导出任意角度、任意朝向都适合按压或书写。

玄武水滴铰链的意义是支持折叠与悬停体验；本文没有记录开合寿命或任意角度承重实测。正式演示前应实际检查所用姿态，不把产品展示图当成操作验收。

读表格和长文档

对于资料密集的任务，优先观察实际缩放比例下能否看清表格列名、脚注与注释。将更多内容缩进一屏并不总是合适：字体过小会增加阅读负担。演示时可用同一份文档在两种姿态中对照，展示“能同时看见什么”，避免只朗读分辨率数字。

看照片和创作内容

高对比显示有利于观察明暗细节，但产品介绍仍应区分屏幕能力、素材质量和应用色彩处理。若工作涉及印刷交付、品牌标准色或多个屏幕协同审核，应建立校对流程，以实际文件和目标输出为依据，不能把广色域直接解释成任何工作流都无需校色。

面向会议展示

让观众清楚看到重点，比把整个桌面塞进展示画面更重要。演示文件应使用足够大的字号，保留对比度，并把临时聊天、个人通知和讲稿从共享画面中移开。外接投影或会议共享的实际输出还受接收端分辨率、软件和连接方式影响。

建议的现场比较

准备一页密集报价表、一张带暗部细节的产品照片和一页16∶9演示。分别检查小字、暗部、边缘裁切以及窗口缩放后的排版。所有比较都采用相同素材和亮度设置，并记录环境光；不在不同条件下得出直接优劣结论。

# 键鼠 触控与手写输入

键盘承担持续和精确的编辑

官网规格列出华为星跃随行键盘、星闪无线连接、1.5mm键程和压力触控板。[S1] 对长段落、表格数字和精确修订，键盘与指针通常更便于持续操作。选购时应试自己的常用快捷键、中文输入、选词和滚动方式，不只凭键盘外形判断体验。

触控用于直接选择和调整

触控适合点选窗口、翻页、放大内容以及快速标注位置。需要连续、细密操作时，应检查目标大小、误触和手臂负担。桌面应用的按钮并不一定都为手指设计；用真实工作页面试验，能发现展示视频中不容易看到的问题。

手写笔把空间关系表达出来

当前款支持 HUAWEI M-Pen 3。笔的官方资料列出4096级压感、星闪连接及书写和空鼠两种模式；不同设备和功能有适配范围，不能与 M-Pencil 系列混为一谈。[S2][S4] 手写的价值包括批注位置、圈出重点、画布局和表达方向关系。它不保证应用能自动理解笔迹含义。

在客户方案中，可以在一张产品页上圈出需要强调的接口，并手绘介绍顺序；在设计沟通中，可以用左右分区说明页面层级。保留文字标签和必要的尺寸说明，可减少接收者对草图的误解。

空鼠与演示控制

M-Pen 3 的官方说明包含按键翻页和按住控制光标；通过笔帽开合切换模式。[S4] 正式汇报前，应检查笔当前模式、连接、光标方向和应用响应。在这里介绍的是华为手写笔能力，不是 Input Agent 的手机姿态控制。

| 键盘与触控板 | 写稿 修订 数字录入 | 输入法 快捷键 选择精度 |

# 鸿蒙系统与应用能力

先确认自己要完成的工作

官网规格页标注 HarmonyOS 6.1；产品页展示的部分更新能力有更高版本条件，例如小艺任务要求 HarmonyOS 7及以上。[S1][S2] 因此介绍产品时，应同时写明能力和条件，不能把页面里出现的所有功能都描述为购机即默认可用。

建议建立应用核对清单：常用应用是否有适用版本；已有文件能否打开和编辑；格式、字体和附件能否保留；协作方能否继续使用输出结果；关键插件、宏、驱动或企业登录是否正常。任何一项缺失，都可能比处理器或屏幕差异更影响日常使用。

办公与创作的生态入口

官方产品页以 WPS、设计绘图、白板和视频剪辑等应用展示折叠工作流，并注明第三方体验随版本优化。[S2] 这些展示可以帮助理解形态用途，但不应被扩大为全部桌面版功能均已等同支持。实际选择应落实到具体应用、文件和功能。

小艺慧记的本地能力需要核验

当前官方 FAQ 将麒麟 X90 Plus 版 Fold 列入本地转写及摘要支持范围；另一篇本地识别说明仍写只支持 MateBook Pro S，两个页面的机型口径不一致。[S7][S8] 本文将其标为“官方资料存在差异，需以设备入口及系统版本核验”，不作所有当前设备均可离线使用的承诺。

本地识别说明还要求先下载模型，下载并不等于已经启用本地处理。[S8] 若在无网会议中使用，应提前做一次断网录音、保存和重开测试。转写后的姓名、金额和行动项仍要人工检查；这属于工作交付质量控制，不能交由自动摘要替代。

对 AI 助手的合理期待

AI 可以帮助组织材料和生成草稿，但引用是否准确、事实是否符合当前版本、结果是否适合对外发送，仍需要使用者检查。产品介绍不应承诺某项助手能够在未授权时操作所有应用，也不应把生成内容当作官方发布的新规格。


# 跨设备协同与文件流转

从文件结果判断协同是否完成

电脑与手机协同的价值，在于缩短拍摄、选材、编辑和分享之间的距离。演示时应让观众看到文件真实到达、能够打开、可继续使用，而不仅是出现“已连接”的状态。以下流程建议不代表在任何网络或设备组合下都会自动成功。

官方键鼠共享说明列出由电脑发起的两设备和三设备组合，并给出系统版本要求；部分机型不适用。[S5] 具体使用还应核对账户信任、无线设置、设备开关和适配版本，不把“都叫鸿蒙设备”当成充足条件。

一条可复现的材料链路

先在手机整理用于项目的照片与资料，采用清楚的文件名；再通过实际可用的分享或协同入口传入电脑。电脑接收后检查文件数量、大小和预览，把材料放入本次项目目录；最后由目标应用真正附加或引用。只把文件名写进提示词，并不代表模型或应用获得了文件内容。

| 阶段 | 应该看到的结果 | 容易混淆的情况 |

| 建立连接 | 目标设备身份明确 | 发现附近设备不等于可写入 |

| 传送资料 | 目标端出现真实文件 | 分享提示不等于传完 |

| 检查资料 | 预览内容与源文件一致 | 有文件名不等于有完整内容 |

| 引用材料 | 目标应用显示附件或引用 | 粘贴路径不等于上传附件 |

| 继续编辑 | 修改后能保存并重开 | 可预览不等于可编辑 |

企业环境与外部展示

使用公司网络时，应先做小文件试传，再安排正式演示。设备发现、文件传输、应用调用和互联网访问是不同环节，一项成功并不证明其余环节正常。若企业有数据管理要求，使用经过批准的材料和传输方式，不在客户会议中临时处理账户或权限问题。

本文的手机文件交付用于提供可选择的参考资料。它与 Input Agent 的文字同步、Mac 桥接或其他控制方式分属不同链路；文档到达手机，不构成这些控制能力已经通过验收。


# 移动办公与客户沟通场景

场景目标

设想业务人员需要在一次出差中完成三件事：路上阅读客户需求，到达现场修改方案，会议结束后整理行动项。选择折叠电脑的意义，应体现在这三项任务能否连续完成，而不是只展示展开屏幕的动作。以下是建议流程，不是产品性能测评。

会前准备

建立一个独立项目目录，把客户需求、产品说明、报价和演示稿分别命名，记录版本日期。将需要现场展示的文件导出可稳定阅读的 PDF，同时保留可编辑原件。准备一份不含私密数据的演示副本，避免在投屏时暴露文件列表、聊天或账户信息。

需要途中完成阅读时，可把当前重点资料单独置顶，减少寻找附件的次数。对不确定的规格或报价条件先加批注，等联网或回到完整资料环境后核实，避免把缺少依据的内容直接写入最终方案。

现场修改

在稳定桌面上展开设备，将原始需求和待修改的方案并列。客户指出问题后，先定位到对应段落或图表，再修改。对空间布局、展陈或产品摆放，可以使用草图表达关系；需要精确尺寸和数量时仍补上文字，防止把示意图当成最终工程要求。

把“采集意见”和“确认方案”分成两个动作。可以先记录多个修改要求，统一核对后再保存最终版本。若需要客户确认，应展示清楚的修改前后差异和文件版本，不用即时写入的速度代替确认过程。

会后交付

整理决定、责任人和截止时间；检查所有附件是否属于本次项目。最终稿与工作稿分开保存，将对外发送的 PDF 与可编辑原件对应起来。自动转写和摘要可以加快整理，但姓名、价格、日期和承诺必须回看原始记录。

怎样衡量是否值得

记录一次真实流程中需要的设备数量、文件找回时间、跨设备传输成功率，以及保存后格式是否保持。若主要阻力来自企业系统或专用插件，先解决兼容问题，再评价折叠形态带来的收益。


# 演示汇报与阅读场景

把主画面与演讲工作区分开

汇报时观众需要看清结论、图表和产品图；演讲者需要看到备注、下一页和时间。两者信息目的不同。建议用已有的六页演示验证应用对双区、外接屏幕和讲稿的实际处理，不预设所有场景都支持同一种演讲者视图。

推荐的现场顺序

先在编辑模式核对六页顺序和字体，再连接实际会议显示设备。打开第一张幻灯片，确认外部画面没有备注、私密文件或通知；然后尝试下一页、上一页、视频播放和返回编辑。把文件存到本机，并提前验证断网时依然能打开关键资料。

若使用笔的空鼠或其他控制器，应在正式开始前确认设备连接、控制对象和按键含义。演示时光标可以帮助指向重点，但持续晃动会分散注意力。需要说明一个细节时再指向，讲完后回到稳定画面。

用于产品介绍的画面组织

首页用一句清楚的产品定位和一张形态图；规格页保留与听众决策相关的数字；应用页展示一个连续任务。对于“展开看资料、折叠做输入”的讲解，优先安排同一份文件在不同姿态下的变化，不用多张互不相干的宣传图代替过程。

长文档阅读

阅读技术资料时，可以保留目录、正文和笔记之间的稳定关系。先确定阅读目的：找某个参数、比较多处描述，还是形成自己的观点。字号、页宽和窗口数量跟随目的调整。对具有版本条件的功能，最好直接把条件记在对应条目旁，而不是另放一份容易遗失的备注。

| 验收项目 | 合格表现 |

| 画面与备注 | 观众只见要展示的内容 讲者可读备注 |

| 翻页与指向 | 每次操作对应明确响应 无重复跳页 |

| 素材播放 | 音视频可正常开始 暂停和结束 |

| 退出与修改 | 可以返回编辑 并保留已完成修改 |

| 离线准备 | 断网后关键文件仍可打开 |

以上为演示验收建议。官方产品页展示了 WPS 汇报用途，但具体视图与第三方应用版本有关。[S2]


# 创作 批注与资料整理场景

先用草图说明关系

在新产品介绍中，文字往往能说明“要讲什么”，但不容易快速说明“内容放在哪里”。草图可以表达标题、主图、分栏和强调区域的相对关系。一个左右分栏布局，加上“产品总览”和“分产品介绍”的标签，比大量含糊的方位描述更容易沟通。

草图应保留原始版本，确认后的图片用于参考；关键意图仍以文字说明。若交给 AI 或同事制作演示，应明确草图控制的页面、可调整的细节和必须保留的元素，避免把某一页布局误应用到所有页面。

先区分照片的用途

同一张照片可能作为事实来源、视觉参考，或最终页面中的插图。这三种用途会影响裁切、清晰度和标注要求。把“参考这个构图”和“把这张实拍放进产品页”分别说清楚，可降低后续返工；图片里包含个人、商业或场地信息时，也应确认使用范围。

分层修改与批注

需要尝试多种表达时，把原图、标注、文字和修改方案分开保存。每完成一个阶段就保留可恢复的版本，避免在同一张扁平图片上反复覆盖。工具能否分层、是否支持导出和重开，必须在实际应用中确认。产品页展示的华为笔记和天生会画说明了创作方向，不替代具体格式兼容验收。[S2]

用于 WorkBuddy 的示例需求

“请根据附件制作六页华为 MateBook Fold 非凡大师产品介绍 PPT，面向正在评估移动办公设备的同事，演讲时长10分钟。只使用附件里核实的当前款参数。背景灰色，主色红色，正文黑色。产品展示页按我的草图左右分栏：左侧产品总览，右侧关键能力。产品照片用于页面插图。保留版本条件，不写未经测试的性能或续航结论。”

这是一条可编辑的输入示例，颜色和布局是演示要求，不是产品外观参数。发送前应确认附件实际进入目标应用，并检查图像和文字引用是否与预期一致。本文没有把示例发送给任何助手，也没有代替用户创建任务。

形成可再次使用的资产

最终目录至少保留资料原件、选用照片、布局草图、可编辑演示和导出 PDF。给每一版结果记录日期和主要变化，下一次更新产品规格时就能定位需要替换的页面，而不必重新整理整套材料。


# 使用维护与选购核对

柔性屏幕的日常维护

官方清洁指引要求先关机、断开外部电源并等待冷却；合盖前注意屏幕和磁吸位置的异物。屏幕应展开平放，用略微湿润的无绒软布轻柔同向擦拭，避免液体进入边缘和接口。屏幕与外壳的清洁方式不同，官方不建议常规使用酒精或其他清洁剂擦屏。[S6]

不要把抗冲击宣传或认证理解为不会损坏。保持运输时的保护和桌面使用时的稳定支撑；出现贴膜、屏幕或铰链问题时按官方服务路径处理，不自行拆解。本文不替代设备随机安全和使用说明。

购买前带着自己的材料试用

| 检查对象 | 建议用什么验证 | 记录结果 |

| 核心应用 | 现用文档 表格 演示及插件 | 能否打开 编辑 保存 重开 |

| 企业环境 | 实际登录 VPN 权限与外设 | 是否符合企业要求 |

| 显示与输入 | 报价表 草图 长段落 | 字号 选区 误触和输入舒适度 |

| 会议设备 | 实际投影 扩展坞与线缆 | 输出 声音 备注与恢复 |

| 多设备协同 | 真实手机及一份测试文件 | 发现 传送 打开和引用 |

| 携带与电力 | 整套出行装备和典型负载 | 重量 充电与连续工作体验 |

服务与成本

总成本应包括主机、需要的配件、软件授权和可能的维修成本。服务权益、活动价格和适用条件随购买时间与渠道变化，应在下单前查看对应商品及服务条款；不要把其他代产品或某次活动的价格直接套到当前款。

什么时候应暂缓替换主力机

如果关键软件尚不能完成现有任务，或者重要文件在保存后出现字体、公式或布局问题，可以先作为辅助设备试用，保留原工作环境。若稳定性问题集中在网络或企业权限，也应先排除这些因素。只有完成自己的高频工作闭环，才能判断它是否适合承担主力工作。


# 六页产品介绍 PPT 提纲

以下为10分钟产品介绍的建议结构，面向业务、产品和设计同事。每页只围绕一个问题展开；页内事实引用本资料，演讲者备注可使用下一页讲稿。时间分配是演示建议。

| 页 | 标题 | 画面与要点 | 时间 |

| 1 | 一台电脑如何适应不同工作姿态 | 产品形态示意 核心问题与定位 | 1分钟 |

| 2 | 把屏幕面积用在资料对照上 | 展开与折叠的同任务对比 18与13英寸 | 1.5分钟 |

| 3 | 选择最适合当前任务的输入方式 | 键鼠 触控 手写 空鼠 各讲一个动作 | 1.5分钟 |

| 4 | 从手机材料走到电脑成果 | 照片或文档的实际传送 检查 引用链路 | 2分钟 |

| 5 | 用完整办公流程评估价值 | 会前准备 现场修改 汇报 会后交付 | 2分钟 |

| 6 | 选择前先核对关键条件 | 应用 文件 外设 版本条件和试用结论 | 2分钟 |

视觉安排

封面突出完整产品名称和麒麟 X90 Plus 版本。第二页可以使用左右对照结构，左侧放工作区域全景，右侧展示同一文件的局部。规格页不要塞满全部数值：选出对听众有意义的三至五个，完整规格留在资料附件中。

第四页以真实文件流转为主，避免用“已连接”图标代替成果。第五页展示一份需求、一次修改和一份最终输出。末页给出可执行的试用清单，让听众知道接下来应该验证什么，而不是只留下功能名。

不可省略的说明

涉及亮度、重量等数字时保留条件；涉及小艺任务时写明系统版本；本地慧记能力注明需核验。不要把 Input Agent 的控制器、Mac WorkBuddy 的提示词理解或第三方模型能力放进华为官方功能列表。使用自制原型画面时应明确标注原型。

五分钟压缩版

保留第1、2、4、6页，每页约一分钟到一分半。输入方式合并到形态页，完整流程用文件链路串联，规格细表和详细兼容说明放到附件。这样缩短的是讲述范围，而不是删掉版本条件或把未经验证的能力说成确定事实。


# 演讲要点与口语化讲稿

开场

“今天我们看这台电脑，先不从参数开始。想象一下，一天里我们可能要在路上读资料，到会议室改方案，最后再把内容讲给别人听。这几个场景需要的屏幕和输入方式并不一样。MateBook Fold 值得讨论的地方，就是它能不能让同一套资料在这些场景里更连贯地使用。”

形态与显示

“展开之后，我们可以把原始资料和正在编辑的内容放在一起看；折叠之后，再根据桌面空间和任务调整上下区域。我们要观察的不是能打开多少窗口，而是重要信息能不能一直看见。屏幕数字可以帮助理解范围，但真正的体验还是要放进我们的文档、表格和演示文件里看。”

输入与创作

“需要长篇修改时，我会优先用键盘；只想点一下或放大某个区域时，用触控更直接；想解释一页内容怎么排，用笔画一下会更清楚。关键是让输入方式跟着任务走。支持手写也不代表软件会自动理解草图，所以标题、用途和重要的尺寸仍然要说清楚。”

材料与协同

“很多工作其实从手机开始，比如拍了一张产品照片、收到一份资料。这里我最关心的，是它能不能真的到电脑上、能不能打开、能不能放进正在做的文件里。连接提示只是第一步，最后我们还要检查引用的是不是正确文件。具体协同功能也要看双方设备和版本，不能只凭同一个品牌就作保证。”

完整流程与选择

“如果我们能把会前资料、现场修改和会后交付连起来，这个形态就有实际价值。反过来，如果最重要的软件、插件或者公司设备用不了，屏幕再大也不能替我们完成工作。所以我建议拿自己的真实项目来试：看一次编辑、保存、重开和传送，记录卡住的地方，再决定它适不适合成为主力电脑。”

结束与提问

“最后留三个问题：我们的高频工作是否需要更大的可携带工作区？现用软件和文件是否已经验证？协同带来的便利是否能在实际环境中重复出现？回答完这三个问题，我们对这台产品的判断就会比只看配置更具体。”

使用方式：以上是可改写的讲述骨架，不是固定10分钟逐字稿。按第13页的时间安排，穿插自己的文件操作、画面比较和现场停留；不要把示范措辞当成已完成的体验报告。
