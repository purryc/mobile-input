# 手机辅助输入与目标接收格式 · 实施记录

日期：2026-11-03。行为规则唯一主源仍为 [Notion 设计规范](https://app.notion.com/p/3f9194db24c38165996cf89b22e7d69e)，本文件记录代码和验证，不是 Design 镜像。

## 已实现

- 共享核心 `projectTargetInput` 接收正文、参数、材料和目标能力，返回纯文本、可采用材料、不可用原因及原文／目标文字位置映射。假 WorkBuddy 与真实 Mac WorkBuddy 手机控制器共用。颜色就地变成 HEX，时长变成数字；普通描述保持原文。手动修改覆盖原参数，不追加“用户调整的参数”造成双值冲突。
- 手机仍使用句内辅助控件；平板新任务及网页演示任务输入框使用普通文本和实际附件卡片。草图是图片附件，正文携带页面用途说明。实际材料仍经现有上传、长度／哈希校验、采用和目标附件确认路径；仅有名字不算附件。
- 真实 WorkBuddy 连续同步和显式发送共用投影。目标读回等于已写入文本时保留手机控件；目标端正文实际变化时替换旧参数。恢复本地资料完成后才开放编辑，避免刚出现的输入框覆盖立即输入的文字。没有附件能力时发送受阻、材料保留，不静默丢失。
- 参数操作绑定原正文；晚到操作不得写入另一版本。同一“新建任务”输入槽使用 owner 代次隔离附件，已发送后返回的旧选择器不能附到下一输入。已有任务仍保存原任务材料。
- 新任务主区依当前 Mac WorkBuddy 5.9.3 调整：办公／开发／设计、七个场景入口、普通输入框、附件／模型／语音／发送工具、工作空间与权限行、建议请求。制作PPT仅准备内容；普通 PPT 请求或该入口明确发送后才启动 Gemini。其他普通任务保留原本地演示处理。模型从原生状态或本地服务状态读取；普通本地演示不冒充真实模型。
- `AGENTS.md` 与 Notion G04、G05、G08、APP-WB-01 已先行更新。保留已有任务结果、网页编辑、播放、手机固定输入区及独立运行路径。
