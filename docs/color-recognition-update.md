# 颜色入口收敛与识别反馈 · 2026-10-14

## 行为

- 手机颜色结果仅保留“调整颜色”入口及入口内的实时色点。移除底部独立颜色参数标签，识别与调色不再向文本追加 `[主色 #……]`。
- 主色仍作为独立任务参数持久化，用于实际生成的销售／Roadmap 成果；关闭面板、切换任务保留手动调色。调色面板内部保留 HEX 精确输入。
- 已有草稿中的系统格式主色标记升级时先备份再清理，用户自写的普通 HEX 文本保留，手绘、附件和其他草稿不重置。
- 正在说话时，已识别到的颜色短语在原文字位置显示青蓝／淡紫扫光，不生成可执行入口。识别结束后稳定 900 ms，再显示“调整颜色”；普通同步、重新进入已有草稿不重播。文字仍由真实 textarea 编辑，高亮层不拦截触摸或光标。
- 删除／否定来源、切换任务或断线取消旧反馈。入口只打开调色，不发送任务。
