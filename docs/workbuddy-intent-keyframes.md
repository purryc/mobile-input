## 主线

1. 口述任务：公司 Roadmap PPT，主色用红色；灰色草稿状态。
2. 稳定识别颜色：框内色词与参数 chip，默认 `#E03131`，中部展开统一颜色输入容器，预设色、调色、色相和 HEX 同时可见。
3. 实时调色：在同一容器点选／拖动或输入合法 HEX，示例改为 `#C92A2A`，立即回写文本框；没有自定义入口或完成步骤；chip、色阶与 HEX 一致，继续口述不覆盖用户值。
4. 稳定识别布局：左右区域词句高亮，中部画板；颜色约束保留。
5. 手绘与确认：右上角48×48关闭，右下角48×48对勾确认，不使用底部通栏大按钮；空画板禁用。确认后收起画板，原始草图作为缩略图附件插入唯一文本框；点击缩略图返回编辑，再确认替换原附件。原始笔迹和解释结构分层保留，文字与色值不丢，确认不发送。
6. 框内检查：文字、主色与手绘附件在同一文本框中检查和修改，不另开Review。
7. 明确提交后执行：顶部绿色执行中与停止入口；详细步骤只在 PC，补充仍属于当前任务。
8. 执行确认完成：顶部蓝色已完成；成果及详情留在 PC，手机不重复成果卡。

框内“纸飞机＋发送”直接提交当前任务并进入执行中；移除独立Review与第二个“提交任务”按钮。颜色选择、草图、收起输入及录音结束均不提交。Figma 中计时完成属于模拟，不能作为设备执行确认。

## 输入和状态约束

- 唯一文本框采用弹性高度：无附加输入时填满中部；出现调色、补材料等控件时，控件占位并压缩文本框，文本框使用剩余高度。手绘保留紧凑文本框。发送固定在框内右下角，顶部任务栏和底部输入区保持原位；不再把中部留空。

- 最小化显示两排固定工具。键盘／触控板为互斥选择：点未选项展开，点另一项切换，再点当前项收起。文本框留在上方并为发送预留空间。
- 键盘保留回车、退格、符号、Emoji；回车插入换行，不发送。触控板左右键不显示文字或箭头，中间保留语音。
- 稳定语义允许在用户继续说话时更新中部，底部语音位置不动。拖动调色、触控、绘制期间延后工具变更，释放后只应用最新目标版本的结果。
- 文本框只承载输入内容及输入参数，不承载 Agent 状态。执行步骤、日志、详细进度和成果详情只在 PC；手机顶部任务追踪保留任务身份、色点和简短状态，必要的停止／继续操作也在此区。材料补充、回答和真实审批仍是手机输入任务。
- 任务状态与连接状态分别绑定区域。草稿灰、执行绿、需输入黄、错误和停止红、完成蓝；红色状态用文字区分出错／已停止，黄色原因区分补材料／审批／澄清。应用主题不改变其含义。
- 颜色预设、自定义调色、色相和 HEX 为同一常驻输入容器；合法修改实时回写文本框 HEX 与草稿，无额外完成操作。布局解释确认与任务提交仍保留。
- 用户修改值优先于推断。非法 HEX 不覆盖最后合法值；撤销移除精确覆盖并恢复原表达。切换任务隔离参数、草图和草稿，返回时恢复。

## 设计验收矩阵

| 输入或动作 | 预期 |
|---|---|
| 主色用红色 | 默认颜色参数与色阶 |
| 自定义 C92A2A | 色点、HEX和文本框同步 |
| C92A2Z | 错误反馈，保留最后合法色值 |
| 不要红色 | 记录排除约束，不选择红色 |
| 指标飘红 | 业务描述，不打开主色工具 |
| 左侧里程碑，右侧关键成果 | 布局画板及解释 |
| 左右为难 | 不打开布局工具 |
| 拖动时新意图到达 | 保持控件，释放后校验目标再更新 |
| 更换任务后旧识别返回 | 丢弃旧结果 |
| 框内发送 | 直接提交并进入执行中 |
| 完成反馈 | 必须有执行端确认，发送不等于完成 |
