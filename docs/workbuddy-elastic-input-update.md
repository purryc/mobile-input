# WorkBuddy 推荐输入与弹性布局 · 2026-10-15

## 当前规则

以用户最新纠正和 Figma `ApFLno64NcMoA17MiPFfZh` 的 `1286:6473` 为准。已读取完整设计上下文和截图；本节取代此前“一个展开工具＋顶部摘要、点正文收工具”的实现。

- 只有当前任务的稳定输入提到相关意图，才在唯一文本框内推荐“调整颜色”“画个布局”等入口。语音中间结果不推断，否定／移除意图后不新增推荐。
- 打开一个工具，只隐藏文本框内对应入口。关闭时移除整个面板，不保留顶部摘要或最小化条；相关意图仍存在时，入口回到文本框。
- 颜色、画板等工具可以同时展开。它们与文本框共同分配中部高度，键盘／触控板展开也参与高度分配。点击正文不关闭工具，打开键盘不关闭工具。工具和正文各自滚动，底部发送与语音保持可达。
- 推荐来自文字；既有草图属于材料。关闭未确认画板仍保留笔迹，以文本框顶部附件访问。删除文字中的布局意图不会凭空推荐布局，也不会删除用户材料。附件可继续编辑／删除，待确认草图仍阻止漏发。
- 新任务、后续补充和材料任务共用规则；切换任务、断线不把工具视图带入其他任务，不清空文本或材料。
