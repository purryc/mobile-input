# Asset provenance

Assets are copied locally from Xiaoyi Work source commit 2c7c428, under apps/web/public.

- assets/xiaoyi-work/design-*.png: original-color expert avatars, skill artwork, connector logos and format icons derived from the supplied WorkBuddy references and Figma; not claimed as official vector assets.
- assets/figma/sentence-parameters/*.svg and reference-assets/workbuddy-widgets/*.svg: the existing Figma input-control exports.
- assets/figma/presentation/noto-sans-sc-*.woff2: existing bundled Noto Sans SC font resources. Noto is distributed under SIL OFL; see OFL.txt alongside these files.
- Brand resources retain their owners' rights. This source handoff does not grant a new trademark or asset license. Replace these resources when your product requires its own licensed assets.

No runtime Figma URL is required. Source design file: https://www.figma.com/design/ApFLno64NcMoA17MiPFfZh

The ten `assets/xiaoyi-work/font-*.png` images are phrase specimens rendered at 3× from verified regular faces of Microsoft YaHei, SimSun, SimHei, KaiTi, FangSong, Arial, Calibri, Times New Roman, Georgia and Consolas. The source faces are locally installed Microsoft Office fonts and the system Georgia font. The previews contain only a fixed phrase in each face. Windows family names and optional language features are documented in the [Windows 11 font list](https://learn.microsoft.com/en-us/typography/fonts/windows_11_font_list).

The Lumina optical skin uses the Latin variable subsets of JetBrains Mono and Plus Jakarta Sans from Fontsource 5.3.0. Their SIL Open Font Licenses accompany the fonts in assets/xiaoyi-work. Chinese glyphs use the existing bundled Noto Sans SC specimens where available.
