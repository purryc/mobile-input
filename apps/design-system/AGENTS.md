# Xiaoyi Work catalog contribution

This branch carries the Xiaoyi Work contribution to the existing Design System. `src/xiaoyi-controls.ts` exports the catalog entries and public views. `src/xiaoyi-controls-preview.tsx` mounts isolated interactive fixtures. Keep fixture state in memory and use only user-selected local media or clearly labeled samples. The regular demo uses the same views with its own application adapters. Integrate the catalog contribution into the main Design System during an explicitly scoped mainline task.
